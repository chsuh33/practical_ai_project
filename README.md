## 실습 코드

- 1~6장: 머신러닝·딥러닝 기초 및 주요 모델 구현
- 8장: AI 프로젝트 설계와 예비 검증을 위한 세 가지 미니 프로젝트
- 13장: PyTorch를 활용한 설계 최적화
- 부록 B: 차원 축소
- 부록 C: 전이학습

## 사용 방법

1. 필요한 장의 `.ipynb` 파일을 다운로드합니다.
2. Jupyter Notebook 또는 JupyterLab에서 파일을 엽니다.
3. 외부 데이터셋이 필요한 실습은 책에 안내된 데이터 출처에서 직접 다운로드합니다.
4. 필요한 Python 패키지를 설치한 후 코드를 순서대로 실행합니다.

데이터셋은 본 저장소에 포함하지 않습니다. 실습에 필요한 데이터 파일 및 실행 환경은 각 Notebook과 책의 설명을 참고하시기 바랍니다.

일부 실습 결과는 실행 환경, 라이브러리 버전 및 난수 초기화에 따라 책에 제시된 결과와 차이가 있을 수 있습니다.
